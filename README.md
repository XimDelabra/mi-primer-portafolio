# Nuestro primer portafolio

Un portafolio web sencillo de Ximena, Eduardo y Leonardo, creado únicamente con HTML y CSS.

## Propósito de la actividad

Este portafolio se hizo con la intención de mostrar cómo funcionan Git y GitHub. La actividad permite practicar el control de versiones, registrar cambios mediante commits y compartir un repositorio para trabajar en equipo.

Es una actividad realizada en equipo por **3 participantes**:

1. Ximena Alessandra Delabra Castillo
2. Jesus Eduardo Gonzalez Lopez
3. Leonardo Sotero Nuñez Ortiz

## Archivos

- `index.html`: contenido del portafolio, con presentación, habilidades, proyectos y contacto.
- `style.css`: estilos y adaptación a pantallas de celular.
- `README.md`: descripción de la actividad.

## Cómo verlo

Abre `index.html` en cualquier navegador. No necesitas instalar dependencias ni ejecutar comandos.

## Cómo personalizarlo

Editen `index.html` para actualizar la presentación del equipo, las habilidades, los proyectos y los datos de contacto. Las ideas de proyectos se pueden completar conforme avancemos.

Pueden cambiar los colores y otros estilos en `style.css`.

## Práctica con Git y GitHub

Después de realizar cambios, puedes registrarlos desde la carpeta del proyecto:

```bash
git status
git add index.html style.css README.md
git commit -m "Crear portafolio sencillo"
```

Con el repositorio remoto de GitHub y la rama de seguimiento ya configurados, usa `git push` para subir los commits y `git pull` para obtener los cambios del equipo.
